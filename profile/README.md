# Quantwala

**Test trading ideas for Indian markets, with costs included.**

Quantwala brings written trading rules, historical backtests and paper practice into one workspace. Inspect estimated Indian charges, trades and drawdowns before interpreting a result.

## Open-source tools

### [indian-trading-charges](https://github.com/Quantwala/indian-trading-charges)

A zero-runtime-dependency Python library for estimating brokerage, STT, GST, stamp duty, exchange fees and breakeven moves across NSE and BSE equity and F&O trades. Decimal arithmetic, explicit rate sources, worked-example tests and an MIT licence.

[Read the code and examples](https://github.com/Quantwala/indian-trading-charges#readme) · [Report an issue](https://github.com/Quantwala/indian-trading-charges/issues)
